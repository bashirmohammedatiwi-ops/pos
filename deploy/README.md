# FOT Web Hub (VPS)

نقطة البيع وSQL تبقى في المحل. السيرفر يخزّن **نسخة آمنة للبائع** ترفعها لوحة التحكم باستمرار. لا نفق.

## المنافذ على السيرفر

| منفذ | الخدمة |
|------|--------|
| **4700** | البوابة العامة |
| **4701** | تطبيق البائعين |
| **4702** | الموظفون — لاحقاً |
| **4703** | المدراء — لاحقاً |
| **4705** | استقبال المزامنة من المحل فقط |

لا يُفتح 80 أو 443 أو 3000 أو 5000 من هنا.

## تحديث الـ VPS

```bash
cd ~/pos
git restore deploy/up.sh || git checkout -- deploy/up.sh
git pull origin main
cd deploy
chmod +x update.sh up.sh
./update.sh
```

يجب أن تظهر الحاويات: `hub` و`seller` و`gateway`. افتح 4700 و4701 و4705 في جدار النار/لوحة Contabo.

## على جهاز المحل

ثبّت خادم نقطة البيع **2.2.66** أو أحدث. بعد تشغيل `FOT POS Server` يرفع الحسابات والعمولات إلى `http://187.124.23.65:4705` كل دقيقة، وفوراً عند توليد رمز من **حسابات الويب**.

لا حاجة لملف نفق.

ثم افتح `http://IP-السيرفر:4701`

## ماذا تُمرَّر من البوابة؟

البوابة تمرّر فقط `/auth/seller-lookup` و`/auth/seller-login` و`/api/seller/`. باقي الـ API مرفوض.

الحسابات تُولَّد من لوحة تحكم المحل: **الفريق والحوافز → حسابات الويب**.
